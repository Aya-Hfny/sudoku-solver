## 1. Problem statement

The project reads handwritten digit images arranged in a 9×9 Sudoku grid. A digit classifier predicts a probability distribution over digits 1–9. Duplicate givens reveal likely recognition errors. A correction-search algorithm proposes low-cost edits, and a Sudoku CSP checks whether the corrected grid is solvable. If no acceptable correction is found within the correction budget, the system reports `unreadable` and lists low-confidence cells.

## 2. Dataset and generated data

The real digit source is MNIST: 28×28 grayscale images, 60,000 official training records and 10,000 official test records. A fixed-seed split takes 50,000/10,000 records from the official training set; label 0 is then removed from each partition, leaving classes 1–9. The official test partition is not used for fitting or calibration. Pixels are converted to float32 and divided by 255.

Sudoku solutions are generated by randomized backtracking. Clues are removed only when the remaining puzzle still has exactly one solution. Synthetic mosaics are assembled from real MNIST images. Injected errors are synthetic and documented; they are chosen to conflict with a peer clue. This dataset is not a collection of photographed real-world Sudoku sheets. See `data/DATA_DICTIONARY.md`.

## 3. Neural network and calibration

The CNN receives one 28×28 grayscale cell and predicts nine logits. Softmax probabilities are used as confidence scores. A positive scalar temperature is fitted on validation logits by minimizing validation negative log-likelihood. Accuracy, confusion matrix, expected calibration error (ECE), and negative log-likelihood (NLL) are reported for validation and held-out test data. A Logistic Regression classifier on flattened pixels and a deterministic subset of up to 20,000 training images is the baseline.

## 4. Search-based correction

A state is the current 81-cell reading. An action changes one cell involved in a duplicate conflict to one of its top three alternative classes. The change cost is

`max(0, log(p(current digit) / p(replacement digit)))`.

This is nonnegative by construction. UCS prioritizes accumulated cost. Greedy Best-First prioritizes a lower bound on the cost of resolving duplicate conflicts. A* combines path cost and the lower bound. The heuristic uses disjoint conflict edges: at least one endpoint of each selected edge must be changed, so the sum of the cheapest endpoint costs is admissible. The correction limit is configurable and defaults to three in the demo.

## 5. Constraint satisfaction solver

There are 81 variables. A clue is a singleton domain and a blank has domain 1–9. Each pair of cells sharing a row, column or 3×3 box must have different values. Backtracking uses MRV and degree tie-breaking. Forward Checking removes a newly assigned value from its peers. AC-3 enforces arc consistency on binary inequality constraints. Optional uniqueness mode stops after two solutions and accepts only exactly one solution. Counters record assignments, backtracks, pruned values and nodes.

## 6. Integrated pipeline

The pipeline performs an initial AC-3 consistency check, searches for low-cost corrections, and tests each conflict-free candidate with CSP. The first solvable corrected reading is returned with a correction log (`row`, `col`, `old`, `new`, `cost`). The result includes search and CSP counters. If no candidate is found within the correction budget, the system returns `unreadable` and lists the least-confident nonblank cells.

The synthetic demo uses deliberately controlled probabilities (52% for the injected wrong reading and 45% for the known correct digit) to demonstrate the algorithm. It is not CNN output. After training, `run_demo.py --mosaic ...` uses the actual CNN and validation-fitted temperature on a generated mosaic.

## 8. Limitations and future work

MNIST provides isolated digits rather than full Sudoku photographs. The mosaic generator assumes known grid boundaries and does not perform camera perspective correction or grid localization. The injected error model is controlled and conflict-based. Future work can add photographed boards, grid/cell detection, more realistic ambiguous handwriting, and a uniqueness-required correction goal.
